# 👁️ Smart Indoor Navigation System for Visually Impaired Individuals
🚀 AI-powered assistive navigation system providing real-time obstacle detection and voice guidance for visually impaired users.

## 📌 Project Overview

The Smart Indoor Navigation System is designed to help visually impaired individuals navigate indoor environments safely and independently using computer vision and audio feedback.

The system detects nearby objects in real time and provides voice-based guidance to the user.

## 🧠 Technologies Used

* Python
* YOLOv8
* Faster R-CNN
* OpenCV
* PyTorch
* pyttsx3

## ⚙️ System Workflow

Smartphone Camera Feed
↓
Frame Processing using OpenCV
↓
Object Detection using YOLOv8 / Faster R-CNN
↓
Bounding Boxes + Labels Generated
↓
Voice Output using pyttsx3
↓
Real-Time Audio Guidance to User

## 🎯 Key Features

* Real-time indoor object detection
* Voice-based obstacle alerts
* AI-powered assistive navigation
* Computer vision for accessibility support
